### Xin chào 👋 Đây là Truyện Kể

[**Truyện Kể (truyenke.com)**](https://truyenke.com) là nơi đọc và nghe audio truyện miễn phí: tiên hiệp, huyền huyễn, vu sư, đô thị. Truyện được dịch Trung → Việt bằng AI, có giọng đọc tiếng Việt ngay trên web.

Ở GitHub này bọn mình chia sẻ vài công cụ nhỏ đã dùng thật trong quá trình làm nội dung:

| Repo | Làm gì |
|---|---|
| [smooth-ken-burns](https://github.com/truyenkecom/smooth-ken-burns) | Biến ảnh tĩnh thành clip dọc 9:16 zoom mượt, không rung (thay cho `zoompan` của ffmpeg) |
| [vi-tts-text-fixes](https://github.com/truyenkecom/vi-tts-text-fixes) | Chuẩn hoá văn bản tiếng Việt trước khi đưa vào TTS: số thành chữ, bỏ ký tự lạ, sửa cụm hay đọc sai |
| [n8n-sheet-priority-queue](https://github.com/truyenkecom/n8n-sheet-priority-queue) | Mẫu Code node n8n: ưu tiên link dán tay trong Google Sheets trước, rồi mới lấy theo sitemap |

📖 Đọc & nghe truyện: https://truyenke.com
